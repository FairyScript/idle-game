## 1. 设计目标与解法

需求里最关键的几条，以及对应的机制：

| 需求 | 机制 |
|---|---|
| 元素合成、靠进度解锁更多元素与配方 | 39 个科技节点组成的科技树；开局只有 3 个配方，其余靠研究解锁 |
| 不同配方产物与**副产物**不同 | 17 个配方，14 个带副产物；副产物不由玩家决定 |
| 主要乐趣是**配平不同产物的合成**来解锁科技树 | 研究持续抽取一组底物，而熔炉槽位有限 → 必须决定并行产线的组成 |
| 获取**贤者之石**（局外成长代币） | 伟业（17 项，每局重置）+ 终局配方「伟大工作」 |
| 需要**消耗玩家产出**的手段 | 研究 / 市场出售 / 下游配方 / 伟大工作 / 轮回；溢出→废渣→拖慢地脉 |
| 元素供给与产物需求**随时间变化** | 5 条地脉各自周期正弦波动 + 12 种随机天象（同时改供给与需求）+ 商品需求周期 |
| 玩家可以**调整产出**，不至于无聊 | 槽位可随时换配方/暂停；市场可买卖；地脉可强化；催化剂可临时改命 |

核心循环：

```
地脉(波动供给) → 熔炉(配方, 副产物) → 仓库(有上限)
                      ↑                    ↓
              研究(持续抽底物) ← 科技树 ← 市场(波动价格→金币)
                      ↓                    ↓
                  新配方/加成          地脉强化/催化剂
                      ↓
                伟大工作 → 贤者之石 → 元升级 → 轮回(贤者之印)
```

## 2. 模拟内核

每个 tick（默认 `dt = 0.1s`）依次执行：

1. **催化剂计时**衰减
2. **天象**推进（到期消退 → 按权重抽取下一个 → 预告）
3. **地脉产出**：`supply[e] = 基础产出 × 地脉科技加成 × 金币强化 × 波动乘数 × 废渣惩罚`
4. 把「运行中的槽位」与「当前研究」整理成作业（job）
5. **供水式配平**（见下）
6. 应用收支、结算溢出（溢出量 → 废渣）、统计净流量
7. 推进研究进度、检查伟业、自动研究

### 2.1 供水式配平（核心算法）

如果简单地按槽位顺序扣料，先声明的槽位会独占稀缺元素，玩家看到的会是"明明两座炉子一样，只有一座在跑"。
所以引擎采用**按比例同时降速**：对每种物质，把它的总需求与可用量比较，超了就等比削减所有需要它的作业。

```
重复 3 轮（直到收敛）:
  for 每种物质 s:
     demand = Σ(需要 s 的作业.需求速率 × 作业.scale)
     avail  = 库存[s]/dt + 地脉流入[s]
     if demand > avail:
         k = avail / demand
         所有需要 s 的作业.scale *= k
```

这样两座熔炉抢同一种元素时会**同时**降到相同效率（有单元测试覆盖）。
研究也作为普通作业参与同一套配平——所以"研究卡住"和"熔炉缺料"是同一个原因。

`avail` 里带 `库存/dt` 项：库存足够时作业可以满速吃库存（不必受产出速率限制），
这就是"先屯一批，再一口气研究"能成立的原因。

### 2.2 关键公式

| 量 | 公式 |
|---|---|
| 地脉供给 | `base × (1 + 地脉科技) × (1 + 0.15 × 金币强化等级) × clamp(wave + 天象 + 催化剂, 0.12, 5) × 废渣惩罚` |
| 供给波 | `wave = 1 + 0.55 × steady × sin(2π·world/period + phase)` |
| 需求波 | `demand = clamp(1 + 0.60 × steady × sin(2π·world/period + phase) + 天象, 0.18, 3.4)` |
| `steady` | `max(0.12, 1 − 星象平衡 − 观星台 − 预知天象)`，即"抹平波动" |
| 售价 | `基础价 × demand × (1 + 价格科技 + 元升级 + 催化剂)` |
| 买入单价 | `基础买入价 / max(0.35, 供给乘数)`（供给丰沛时便宜） |
| 仓储上限 | `基础上限 × (1 + 仓储科技 + 元升级)` |
| 废渣惩罚 | `max(0.3, 1 / (1 + min(废渣, 900) × (1 − 减免) / 400))` |
| 进度推进 | `Δ进度 = dt × scale / (科技耗时 / 研究速度)`；中途换研究不清零 |

### 2.3 废渣：让"消耗产出"变成必须做的事

- 产物超出仓储上限时，超出部分被浪费，并且**在线时**按 50% 折算成废渣
- 废渣按 `0.12%/s + 0.01/s` 自然挥发（避免无限堆积）
- 废渣拖慢所有地脉 → 直接降低整条产链的吞吐
- 清除手段：`净化·废渣` 配方（吃废渣产盐）、`净火` 催化剂（90 金清 60 点）、科技减免

**离线时不产生废渣**（只浪费产出）。这是刻意的：挂机游戏不该惩罚玩家睡觉。
回到游戏后仓库是满的，玩家需要自己决定卖掉什么——但不会被"睡了一觉地脉慢了 60%"惩罚。

## 3. 数值表

数值设计的三条锚点：

1. **开局 3 座熔炉的总元素消耗略高于地脉供给**（火 1.67/s vs 1.5/s），让玩家在头一分钟就遇到第一次"缺料"，从而学会换配方。
2. **科技耗时的总和 ≈ 主轴 10 分钟**，但实际耗时要乘上"产能爬坡"与"槽位不足"的系数，所以熟练玩家 ~24 分钟摸到终局配方。
3. **单局贤者之石 ≈ 300**，而一项元升级的首级价格 3~20 石、满级总价几百到上千石 → 第一轮能买到 4~6 项升级，形成明确的"下一轮更强"预期。

## 4. 物质链与"配平"为什么成立

```
水 ─┬─→ 盐 ────────────────┐
    ├─→ 铜 ─→ 银 ─→ 金 ─┐  │
火 ─┼─→ 硫 ─→ 铅 ─→ 锡 ─→ 铁 ─→ 铜
    │        ↑   ↑    ↑
土 ─┼─→ 铅   │   │    │
    │        │   │    │
风 ─┴─→ 水银  │   │    │
        ↓     │   │    │
   以太 ─→ 星之精华 / 虚之精华 ─→ 万能溶剂 ─→ 万应灵药 ─→ 贤者之石
```

几个刻意设计的**闭环与冲突**（这是"配平"手感的来源）：

- **黄金喷铅**：`银+硫+火 → 金`，每 1 金副产 2 铅。而铅是锡、铁、虚之精华的原料 →
  炼金越多，铅越堆；要么喂给下游，要么卖掉（而且"铅市崩塌"天象会砸价）。
- **铁与铜互相喂**：`铁+水+硫 → 铜`（副产铁），`铜+汞+水 → 银`（副产铜）→ 上游永远有回流。
- **硫磺是全网最忙的物质**：煅烧产出、升华副产、炼铁副产三个来源；
  铅、铜、金、虚之精华、多种研究都要吃它。硫磺断供是最常见的研究卡点。
- **以太单点瓶颈**：只有一个配方产能，且多个高阶配方抢它。
- **副产物不能被"取消"**：想稳定产银就必须接受同时来铜；想产金就必须处理铅。

## 5. 科技树结构

40 个节点，5 条支线（`main / ley / build / trade / meta`）：

- **main（13 个）**：物质阶梯，每级解锁下一个配方。史诗感的来源。
- **ley（6 个）**：地脉产出 + 波动抹平。对抗"供给随时间变化"的正解。
- **build（12 个）**：熔炉槽位、仓储、全局速度、废渣减免。槽位是最大的瓶颈。
- **trade（7 个）**：售价、研究速度、观星（预告时长）。
- **meta（2 个）**：为下一轮铺路的三合一加成。

节点耗时的设计意图：**支出 6~30 单位的单一种类物质（早期）→ 支出十几种物质（后期）**。
后期一个节点动辄要 4 种产物各 16 个，而熔炉只有 8 座 —— 这就是"配平"的最终考题。

完整表见 `tables.generated.md` 的「科技树」小节。

## 6. 天象与波动

- 每条地脉独立正弦波动，幅度 ±55%，周期 96~300s → **同时最多有 5 个独立相位**，
  所以总有某条地脉在低谷、另一条在高峰，玩家总能在"换配方"里找到局部最优。
- 天象每 16~50s 触发一次，持续 40~55s，**同时**改供给与需求。
  例：`日蚀` 让火供给 −0.5、水 +0.5，同时水银与金的需求 +0.7/+0.6
  → 聪明的玩家会提前把熔炉切到"吃水、产金"的配置。
- 天象有**预告**（默认提前 26s，`预知天象`元升级每级 +6s）。
- `steady`（星象平衡 / 观星台 / 预知天象）是"降低方差"的成长轴：
  它让爆仓与断供都变少，属于典型的"稳健流派"升级。

## 7. 局外成长

### 贤者之石的来源

| 来源 | 数量级 | 重置 |
|---|---|---|
| 伟业 17 项 | 合计 192 石（受「伟业铭刻」×1.35 放大） | 每局重置，可反复拿 |
| 伟大工作配方 | 1 石 / 20s × 全局速度 | 每局重置 |

### 消耗

- 9 项**元升级**（首级 3~20 石，成长 1.45~2.2 倍）：起始地脉、永恒流速、广阔仓库、
  市场洞察、额外熔炉、研究火花、预知天象、伟业铭刻、净化精通
- **轮回**：`贤者之印 = floor((本局贤者之石 / 15) ^ 0.65)`，门槛 40 石，每枚 +4% 全局速度

轮回曲线的实测：75 分钟 → ~290 石 → 6 印（+24%）；1000 石 → 14 印。是平方根以下的凹曲线，
鼓励"多次轮回"而不是"一次憋大招"。

## 8. 平衡实测（自适应机器人）

`tools/playtest.ts` 实现了代表"会玩的玩家"的策略：可达性 BFS 只研究能产出的科技、
按"目标库存 − 实际库存 − 净流量"给缺口打分排产、库存接近上限时强烈回避。
`test/balance.test.ts` 用它作为回归护栏。

单局（无元升级、无贤者之印）：

| 时间 | 事件 |
|---|---|
| ~30s | 完成《金属引论》 |
| ~1m10s | 第一颗贤者之石（首个伟业） |
| ~3m | 4 座熔炉 |
| ~8m | 6 座熔炉，白银链打通 |
| ~14m | 以太上线 |
| ~23m30s | 解锁【伟大工作】 |
| ~35m | 40 / 40 科技全部完成 |
| ~75m | 本局贤者之石 ~292，可得 6 枚贤者之印 |

第二局（+24% 速度，已购若干元升级）：**44 秒**拿到第一颗贤者之石，30 分钟再次点满 40 项科技，~320 石。

关键结论：

- 主线无死结：机器人 40/40 全覆盖，没有"必须拥有某物才能产出某物"的循环依赖。
- 数值发散受控：所有库存、金币、PS 都保持有限，且被仓储上限自然封顶。
- 全局速度 1.0 → 2.25（科技 + 元升级 + 印记），第二轮的主观速度提升非常明确。

## 9. 未做的事 / 后续可扩展方向

- **主动技能**：目前所有干预都是"调配置 + 花金币"，没有需要即时反应的按钮。
  可以加一个"手动投料"操作来换取短时爆发。
- **多周目剧本**：现在每局的唯一变量是元升级与天象随机；可以加入不同的初始元素（例如"只有火与风"的开局）。
- **成就/统计面板**：数据（累计产出、天象统计）已经在 `state.produced` 里，只是没做展示。
- **云存档**：目前只有 localStorage；纯前端约束下可以用导出/导入 JSON 代替。
